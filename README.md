# راياتي · RAYATI
> **تيفو الملاعب الرقمي الأول في الجزائر · Algerian Stadium Crowd Light Show**  
> *آلاف الهواتف في المدرجات تصنع لوحة وطنية موحدة. هوية جزائرية، تصميم احترافي، كود خفيف، و0 تكلفة تشغيل.*

---

## 🌟 مميزات المشروع (Features)

1. **الرؤية الحاسوبية بديلة لملصقات الكراسي (Computer Vision & Homography):**
   - لا حاجة لإلصاق أكواد QR على آلاف الكراسي أو إجبار المناصرين على التقيد بأرقام التذاكر.
   - الهاتف يرمش برمز **Gray Code** خاطف لمدة 5 ثوانٍ، وكاميرا واحدة من المنصة المقابلة تفك الشفرة وتصحح زاوية المدرج المائلة عبر **الهوموجرافيا (Homography Matrix 3x3)** لتحديد موقع كل هاتف في الملعب تلقائياً.
2. **التأكيد الأخضر اللحظي والاهتزاز (Instant Green Lock):**
   - بمجرد اكتمال المسح، تتحول شاشة الهاتف لحظياً إلى اللون **الأخضر الزمردي الزاهي (`#0A7D3E`)** مع خاتم ذهبي، رنة نغمة واهتزاز هابتيك (`navigator.vibrate`) لتأكيد الارتباط بالعرض.
3. **100% أوفلاين في الملعب (Zero Network Dependency):**
   - ملف العرض مضغوط بحجم أقل من 100 كيلوبايت لـ 10,000 مقعد، يتحمل مسبقاً عبر **Service Worker** ويعمل تماماً بدون إنترنت في الملعب استناداً لساعة الهاتف المحلية ودقة `requestAnimationFrame`.
4. **ستوديو برمجة الدخلة (Tifo Studio & Customizer):**
   - تصميم وتخصيص التيفو مباشرة في المتصفح:
     - 🇩🇿 العلم الوطني الجزائري المتحرك (موجات + نجمة وهلال)
     - 🌊 موجة المدرجات (OLA الضوئية المنسابة عبر الأقسام)
     - ⚡ كراكاج الألتراس (نبضات ضوئية فائقة السرعة مع إيقاع الطبول)
     - ⚽ ألوان أندية الرابطة المحترفة الأولى (MCA, USMA, JSK, CRB, ESS, MCO, CSC)
     - 💾 تصدير فوري لملف `show.json` بنقرة واحدة.
5. **تجربة حية على 4 هواتف (Live 4-Phone Sync Test):**
   - شاشة مخصصة تعرض 4 هواتف افتراضية متزامنة مباشرة على شاشة الحاسوب + 4 أكواد QR لتجربتها على هواتف حقيقية عبر نفس شبكة الـ Wi-Fi.
6. **دليل الاستخدام المصور (`guide.html`):**
   - صفحة عامة مصممة بأعلى معايير الـ UI/UX، خالية من أي شعارات أندية أو وجوه أشخاص مباشرة، مع رسومات وصور ثلاثية الأبعاد لشرح التقنية للجماهير.
7. **خفة استثنائية (Ultra-light Performance):**
   - حجم حزمة التطبيق للهاتف فقط **35.9 KB gzip** (الميزانية المسموحة 150 KB).
   - حجم ملف 9700 مقعد فقط **2.3 KB gzip** (الميزانية المسموحة 400 KB).

## 🚀 تشغيل المشروع محلياً (Quick Start)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إطلاق خادم التطوير مع دعم الشبكة المحلية للهواتف:
```bash
npm run dev -- --host
```
* سيظهر لك رابط مثل: `http://192.168.1.X:5173/`
* افتح هذا الرابط من أي هاتف متصل بنفس شبكة الـ Wi-Fi أو بنقطة اتصال (Hotspot) هاتفك!

---

## 📱 كيفية تجربة العرض على 4 هواتف في نفس الوقت

1. افتح صفحة المحاكاة في حاسوبك:
   `http://localhost:5173/simulation.html`
2. اضغط على تبويب **"📱 Test Direct sur 4 Smartphones"**.
3. ستشاهد:
   - **4 هواتف ذكية افتراضية (Mockups)** تتغير شاشاتها في نفس اللحظة بألوان مقاعدها.
   - **4 أكواد QR حقيقية** للمقاعد الأربعة (أخضر العلم، أبيض العلم، الهلال الأحمر، وأحمر العلم).
4. امسح الأكواد الأربعة من 4 هواتف مختلفة، واضغط زر **"⚡ Lancer le compte à rebours 10s"** لمشاهدة التزامن المطلق بالمليثانية!

---

## 🎨 تجربة ستوديو برمجة الدخلة (Tifo Studio)

1. في صفحة `simulation.html`، اضغط على تبويب **"🎨 Studio de Programmation"**.
2. اختر نوع التيفو (علم الجزائر، موجة OLA، كراكاج ألتراس، أو نادي جزائري).
3. اضغط **"⚡ Appliquer immédiatement au stade"** لمشاهدة التيفو يتحرك مباشرة على شبكة الـ 10,000 مقعد.
4. اضغط **"💾 Télécharger show.json"** لتحميل ملف العرض الجاهز للنشر.

## 📖 صفحة الدليل المصور للجماهير (Public Guide)

* افتح الرابط:
  `http://localhost:5173/guide.html`
* تحتوي على صور توضيحية عالية الجودة:
  - صورة الدخلة الليلية لعلم الجزائر بـ 50 ألف هاتف.
  - مخطط الرؤية الحاسوبية وتحويل الهوموجرافيا (Computer Vision & Homography).
  - شاشة التأكيد الأخضر الزمردي باليد والخاتم الذهبي.
  - صورة ظلال الجماهير في الفيراج وهي ترفع الهواتف نحو الميدان.
* تدعم التبديل اللحظي بين العربية، الفرنسية، والإنجليزية مع انعكاس RTL/LTR تلقائياً.

## 🐍 أدوات بايثون والرؤية الحاسوبية (Python & OpenCV)

المشروع يحتوي على بيئة بايثون مجهزة مع **OpenCV 5.0** و **NumPy**:

```bash
# توليد خريطة المقاعد لأي حجم ملعب
.venv\Scripts\python.exe tools/generate_seats.py --out public/seats.json

# تحويل صورة أو شعار إلى ملف show.json RLE
.venv\Scripts\python.exe tools/build_show.py --image tools/assets/flag.png --out public/show.json

# تشغيل أداة تصحيح المقاعد بالرؤية الحاسوبية و Gray Code
.venv\Scripts\python.exe tools/opencv_calibrate.py --video calib.mp4 --out corrections.json

# تجربة خط المعالجة البصرية بالكامل مع فيديو اختباري
.venv\Scripts\python.exe tools/test_calibration_pipeline.py
```

## ☁️ النشر المجاني على Cloudflare Pages (Zero Cost)

1. قم برفع المستودع إلى GitHub.
2. ادخل إلى لوحة تحكم [Cloudflare Dashboard](https://dash.cloudflare.com/) > **Workers & Pages** > **Create Application** > **Pages** > **Connect to Git**.
3. اضبط إعدادات البناء:
   - **Framework preset:** `None` (أو Vite)
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. اضغط **Save and Deploy**.
5. ستحصل على رابط عالمي مجاني فائق السرعة يدعم الـ Service Worker وملايين الزوار شهرياً بـ **0 دينار جزائري** مدى الحياة!
